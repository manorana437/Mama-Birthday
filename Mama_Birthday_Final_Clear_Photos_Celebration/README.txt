MAMA BIRTHDAY PREMIUM WEBSITE

1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Click "Open My Heart" to start the music.

Updates:
- Photos use object-fit: contain, so each full photo remains visible and is not cropped/half-hidden.
- Balloon buttons use heart and kiss emojis.
- Clicking a balloon creates a celebration burst of hearts, kisses and sparkles.
- Uses only HTML, CSS and JavaScript.
